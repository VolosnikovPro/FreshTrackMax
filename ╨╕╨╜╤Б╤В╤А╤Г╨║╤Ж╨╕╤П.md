Инструкция по работе с FreshTrack

1. Вход в систему

Откройте адрес приложения в браузере. Откроется страница входа.

Вариант А — логин/пароль:
- Введите admin / admin123 (или свои данные, если администратор создал другой аккаунт)
- Нажмите Войти

Вариант Б — через Telegram (если настроено):
- Нажмите кнопку «Войти через Telegram»
- Подтвердите вход в открывшемся окне Telegram

После входа вы попадёте на Дашборд.

---
2. Выбор объекта (филиала) — только для администратора и управляющего

В верхней шапке, рядом с названием «FRESH Track», есть выпадающий список объекта.

- Если вы администратор или управляющий — можете переключаться между филиалами. Все списки (продукты, партии, расход, себестоимость, питающиеся) сразу покажут данные выбранного объекта.
- Если вы кладовщик или управляющий по питанию — видите только свой объект, переключать нельзя.

▎ После выбора объекта он запоминается. При следующем входе откроется тот же филиал.

---
3. Дашборд (главный экран)

Здесь — сводка по текущему объекту:
- Всего продуктов — сколько номенклатур в справочнике
- Активных партий — сколько партий с ненулевым остатком
- Срочных сроков — партий, у которых срок годности заканчивается ≤ 16 дней
- Плановых сроков — партий, у которых срок заканчивается ≤ 46 дней
- Потребление за сегодня — сумма списанного за текущую дату
- Питающиеся за сегодня — количество человек на сегодня

Нажмите на любой блок — откроется соответствующий раздел.

---
4. Продукты (справочник номенклатуры)

Что здесь: список всех продуктов текущего объекта.

Фильтры сверху:
- Активные — только те, что в работе (по умолчанию)
- Все — включая архивные/удаленные

Действия:
- Добавить (кнопка «+» справа внизу) — заполните:
  - Название обязательно
  - Единицу измерения (кг, л, шт и др.)
  - SKU/артикул — опционально
  - Категорию — опционально
  - Описание — опционально
- Редактировать (иконка карандаша) — меняет название, единицу, SKU, категорию, описание
- Удалить (иконка корзины, только админ) — помечает продукт как неактивный (в историю не удаляется)

Поиск — фильтрует список по названию в реальном времени.

---
5. Партии / Сроки годности

Что здесь: все полученные партии с остатками и сроками годности. Работает FEFO (First Expired — First Out): при списании расхода списывается сначала партия с ближайшим сроком.

Колонки:
- Продукт
- Номер партии
- Остаток
- Единица
- Срок годности
- Дней до окончания (цветной бейдж: 🔴 ≤16 дней, 🟡 ≤46 дней, 🟢 >46 дней)
- Поступление
- Примечание

Фильтры сверху:
- Все / Срочные / Плановые — быстрый доступ к группам сроков
- Поиск по названию продукта

Добавить партию (+):
- Выберите продукт из списка
- Номер партии (произвольный)
- Количество
- Единица измерения
- Срок годности обязателен — календарь
- Дата поступления (по умолчанию сегодня)
- Примечание — опционально

Редактировать / Удалить (только админ) — редактирует или удаляет запись партии.

▎ Важно: если остаток партии становится 0 (через списание расхода), партия не удаляется, а переходит в архив. В списке с фильтром «Все» она остаётся видна с нулевым остатком — для аудита.

---
6. Расход сырья (FEFO-списание)

Что здесь: учёт ежедневного списания сырья. При сохранении система автоматически списывает количество с партий по FEFO (сначала те, у которых раньше срок годности).

Форма добавления (+):
- Продукт обязательно — выбор из списка текущего объекта
- Количество обязательно — сколько списать
- Единица — подтягивается из продукта, можно поменять
- Дата — по умолчанию сегодня, можно выбрать другую
- Примечание — опционально (например, «ужин», «брак»)

Что происходит при сохранении:
1. Система проверяет, хватает ли суммарного остатка по всем партиям этого продукта
2. Если не хватает — покажет ошибку: «Недостаточно запаса: доступно X, нужно Y» — запись не создастся, остатки не изменятся
3. Если хватает — списывает с партий по FEFO:
  - Ближайшая по сроку партия отдаёт столько, сколько есть
  - Если её не хватило — переходит к следующей по сроку
  - Партия, у которой остаток стал 0, архивируется (не удаляется)
4. Создаёт запись в журнале расхода с примечанием, из каких партий и сколько списалось (например: «Списание FEFO: Партия 1: 4.0 2026-09-01; Партия 2: 2.0 2026-12-01»)

Журнал расхода (основной список на странице):
- Показывает все записи за выбранную дату (фильтр даты сверху)
- Колонки: дата, продукт, количество, единица, примечание (с детализацией по партиям)
- Можно удалить запись (только админ) — тогда остатки партий вернутся обратно

---
7. Себестоимость (цены сырья)

Что здесь: цены за единицу продукта для расчёта стоимости расхода.

Добавить (+):
- Продукт
- Цена за единицу
- Дата вступления в силуСписок показывает актуальные цены. Можно редактировать/удалять (админ).

Импорт из Excel/Google Sheets (см. раздел 11).

---
8. Питающиеся (головы)

Что здесь: количество людей, на которых готовят, по дням. Нужно для расчёта норм расхода на человека.

Добавить (+):
- Дата
- Количество человек

Список показывает записи по датам (фильтр периода сверху). Редактировать/удалить — админ.

---
9. Уведомления

Что здесь: ручной запуск проверки сроков годности и история отправок.

Кнопки:
- Проверить срочные (≤16 дн.) — найдёт все продукты с партиями, у которых срок ≤ 16 дней, сформирует сообщение и (если настроен Telegram) отправит отвественным лицам (админам, управляющим, кладовщикам). Запишет запись в историю.
- Проверить плановые (≤46 дн.) — то же для сроков ≤ 46 дней.

История уведомлений (таблица внизу):
- Тип (срочное / плановое)
- Дата/время отправки
- Сколько продуктов попало в уведомление
- Сколько получателей получило сообщение
- Текст сообщения

▎ Уведомления уходят только тем, у кого в профиле заполнен max_user_id (Telegram ID). Без него — запись в историю создаётся, но сообщение в Telegram не уходит.

10. Администрирование (только для роли admin)

Доступно через пункт меню «Администрирование» (значок щита).

10.1 Пользователи

Список всех пользователей объекта.

Добавить пользователя (+):
- Логин обязательно
- Отображаемое имя
- Роль — одна из:
  - admin — полный доступ ко всему, управление пользователями и объектами
  - manager — видит все объекты (если их несколько), может управлять продуктами, партиями, расходом, себестоимостью, питающимися, уведомлениями
  - storekeeper — работает только со своим объектом: продукты, партии, расход, питающиеся
  - nutrition_manager — только просмотр: продукты, партии, себестоимость, расход (только чтение)
- Пароль обязательно
- max_user_id — Telegram ID для уведомлений (опционально, число)
- Объект — привязка к филиалу (для кладовщика/УПП фиксируется их объект)

Действия: редактировать (имя, роль, пароль, привязку к объекту), деактивировать, удалить (админ).

10.2 Объекты (филиалы)

Список всех филиалов системы.

Добавить (+):
- Название обязательно
- Код обязательно (короткий латинский идентификатор, напр. ASACH, BR2)
- Описание — опционально
- Активен — галочка

Действия: редактировать, деактивировать (мягкое удаление — объект исчезает из выбора, но данные остаются).

10.3 Импорт из таблиц

Два формата:

A. Риск-Отчет (продукты + партии + сроки)
Excel-файл со структурой:
| Наименование товаров | Ед. Изм. | Количество | Срок годности | Комментарий |
| Сыр Гауда            | кг       | 5          | 45123         | проверить   |
- Срок годности — Excel-серийный номер даты (число, например 45123), не текст «2026-09-01»
- Создаёт/обновляет продукты и партии с указанными остатками и сроками

B. Себестоимость (цены + остатки)
Excel-файл:
| Код | Товар   | Ед. изм. | Цена | Остаток | 1 | 2 | 3 |
|1   | Сахар   | кг       | 120  | 50      |   |   |   |
- Ищет заголовок «Код | Товар | Ед. изм. | Цена», данные идут ниже пустой строки-разделителя
- Создаёт/обновляет цены в справочнике себестоимости

Как загрузить:
1. Нажмите «Выбрать файл» → укажите .xlsx
2. Выберите тип импорта: «Риск-Отчет» или «Себестоимость»
3. Нажмите «Импортировать»
4. Результат покажет: сколько создано, обновлено, пропущено, ошибки

▎ Также можно импортировать из Google Sheets — вставьте ссылку на таблицу или её ID, выберите лист (если несколько), тип импорта.

Частые вопросы

«Не даёт списать расход — пишет "Недостаточно запаса"»
- Проверьте, есть ли партии этого продукта с ненулевым остатком на текущем объекте (раздел «Партии»)
- Нельзя списать больше, чем есть суммарно по всем партиям

«Партия исчезла после списания до нуля»
- Она не удалена, а заархивирована. В разделе «Партии» включите фильтр «Все» (или посмотрите вручную через API с include_archived=true)

«Не приходят уведомления в Telegram»
- У пользователя должен быть заполнен max_user_id (числовой Telegram ID)
- Пользователь должен иметь роль admin, manager или storekeeper и быть активным
- Проверьте историю уведомлений — там видно, скольким отправилось

«Хочу видеть данные другого филиала»
- Только admin и manager могут переключать объект в шапке. Кладовщик и УПП привязаны к своему объекту жёстко.

«Как сделать так, чтобы кладовщик видел только свой склад?»
- При создании пользователя роли storekeeper укажите ему site_id нужного объекта. Он не увидит переключатель и будет видеть только данные этого объекта.

---
Горячие клавиши / удобства

- Enter в формах — сохраняет (как нажатие кнопки «Сохранить»)
- Escape в модалке — закрывает без сохранения
- Поиск работает сразу при вводе (без лишних кликов)
- Таблицы сортируются по клику на заголовок (где применимо)

---
Поддержка

Если что-то не работает:
1. Проверьте, что вы на правильном объекте (шапка)
2. Обновите страницу (F5) — иногда помогает после изменений прав3. Ошибки с текстом «401» / «403» — сессия истекла или нет прав → выйдите и зайдите снова
3. При ошибках импорта — посмотрите колонку «Ошибки» в результате, она подскажет, в какой строке проблема
