Инструкция для «чайника»: как пользоваться доработками

0. Первый запуск (админ)

1. Откройте сайт, нажмите Вход.
2. Логин admin, пароль admin123 (создаётся само кнопкой «Инициализировать», если БД пустая).
3. Если забыли пароль — кнопка seed-admin внизу формы входа.

1. Несколько объектов (филиалы)

- Зайдите как админ → вкладка «Администрирование» → «Объекты» → «Новый объект».
- Заполните Название + Код (напр. ASACH), сохраните.
- В шапке сверху появится выпадающий список объектов — переключайте между филиалами, и все списки (партии, продукты, расход) покажут данные выбранного объекта.
- Кладовщик/управляющий по питанию видят только свой объект (без выбора).

2. FEFO (списание по сроку годности)

- Вкладка «Расход сырья» → выберите продукт, укажите количество → Сохранить.
- Система сама спишет сначала из партии с самым ранним сроком годности. Остаток переносится на следующую партию автоматически.

3. Архив нулевых партий

- Вкладка «Партии / Сроки»: когда партия доходит до 0, она не удаляется, а остаётся в истории (видна при включении «показать архивные»).
- Удалить партию вручную может только админ или управляющий.

4. Защита от отрицательного остатка

- Попытка списать больше, чем есть в сумме по всем партиям → ошибка «Ошибка списания: недостаточно …», ничего не списывается, остаток не уходит в минус.

5. Роли и права

- Админ — всё, включая объекты, пользователей, себестоимость.
- Управляющий — партии/расход/питающиеся/объекты (без удаления пользователей).
- Кладовщик — партии и расход (без удаления, без себестоимости).
- Управляющий по питанию — только просмотр.
- Нового пользователя создаёт админ во вкладке «Администрирование» → «Пользователи».
